## Анализ воронки пути пользователя для маркетплейса YouSell

### Контекст:
YouSell - маркетплейс товаров для дома, красоты и спорта. Компания привлекла 10 000 зарегистрированных пользователей за 3 месяца (январь–март 2024).
Запрос от бизнеса, понять как выглядит путь пользователя в приложении, на каком этапе теряем основную массу пользователей.

### Цель проекта:
Построить воронку пути клиента, найти шаги с максимальным оттоком пользователей и предложить рекомендации для роста конверсии в покупку.

---
### Задачи проекта:
- проверка качества данных, поиск аномалий;
- построение общей воронки по уникальным пользователям;
- построение воронки в разрезе по категориям товаров, городам, полу и возрасту;
- подготовка выводов и рекомендаций на основе анализа.

[посмотреть SQL скрипты](https://github.com/dianaborisova3/Yousell_funnel_analysis/tree/main/sql)

---
### Методология и инструменты:
PostgreSQL, Redash, SQL (CTE, оконные функции, JOIN, FILTER, CASE).

[посмотреть методологию](https://github.com/dianaborisova3/Yousell_funnel_analysis/blob/main/docs/02_methodology.md)

### Источники данных:
- PostgreSQL, 5 таблиц: customer_actions, customers, products, orders, order_items.
- Период: 01.01.2024 - 31.03.2024 (91 активный день).
- Объем: 126 405 событий, 7 399 активных пользователей, 5 110 заказов.

[посмотреть полный словарь данных](https://github.com/dianaborisova3/Yousell_funnel_analysis/blob/main/docs/01_data_dictionary.md)

### Ключевые результаты:
- Общая воронка (7 399 пользователей):

| Шаг | Пользователи | Конверсия |
|---|---|---|
| Page View | 7 399 | - |
| Add to Cart | 6 966 | 94.15% |
| Purchase | 3 187 | 45.75% |

- Сквозная конверсия (Page View - Purchase): 43.07%
- Главный вывод: верх воронки работает отлично - 94% пользователей переходят от просмотра карточек товара к добавлению в корзину, но 54% пользователей, имеющих корзину, не завершают покупку. Проблема проявляется одинаково во всех категориях, городах и демографических группах.
- Дополнительные инсайты:
  - 26% зарегистрированных (2 601 человек) не сделали ни одного действия - проблема онбординга.
  - Checkout не обязателен: 45.5% покупок совершаются без явного шага оформления заказа. У Checkout нет order_id, связать его с заказом нельзя.
  - 24.6% заказов возвращены - высокий показатель, требующий внимания.

---
### Рекомендации:

1. Разобраться с брошенными корзинами (54% drop-off) - главная точка роста.
2. Улучшить онбординг: 26% зарегистрированных не доходят до первого действия.
3. Проверить процесс оформления заказа: 45% покупок без Checkout - либо фича (покупка в один клик), либо баг логирования.
4. Разобраться с возвратами (24.6%): причины, влияние на LTV.
5. Улучшить доставку в городах с низкой конверсией (Воронеж, Тольятти, Тюмень).
