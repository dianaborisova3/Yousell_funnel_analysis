## 1. customer_actions - логи действий

Основная таблица для анализа воронки, каждая строка - одно событие пользователя.

| Поле | Тип | Описание | Пример | NULL |
|---|---|---|---|---|
| customer_id | int | ID пользователя | 10482 | нет |
| event_timestamp | timestamp | Дата и время события | 2024-02-14 09:58:00 | нет |
| event_type | varchar | Тип события | Page View | нет |
| product_id | int | ID товара, к которому относится действие | 7781 | да |
| order_id | int | ID заказа | 550123 | да |

Значения event_type:

| Значение | Событий | Пользователей | Описание |
|---|---|---|---|
| Page View | 80 432 | 7 399 | Просмотр карточки товара |
| Add to Cart | 33 176 | 6 966 | Добавление товара в корзину |
| Checkout | 7 687 | 4 116 | Переход к оформлению заказа |
| Purchase | 5 110 | 3 187 | Совершение покупки |

Особенности:

- product_id заполнен только у Page View и Add to Cart. У Checkout и Purchase - NULL, потому что заказ содержит несколько товаров.
- order_id заполнен только у Purchase, у остальных событий - NULL.
- Один заказ - это одно событие Purchase.
- Дублей нет, проверено по customer_id, event_timestamp, event_type, product_id.
- Потерянных записей нет: все customer_id есть в customers, все product_id есть в products, все order_id есть в orders.
- у Checkout нет order_id, поэтому связать чекаут с конкретным заказом нельзя.

## 4. order_items - состав заказов

| Поле | Тип | Описание | Пример | NULL |
|---|---|---|---|---|
| order_id | int | ID заказа | 550123 | нет |
| order_item_id | int | ID позиции в заказе | 1 | нет |
| product_id | numeric | ID товара | 7781 | нет |
| price | int | Стоимость позиции, руб. | 1290 | нет |

Особенности:

- price - итоговая стоимость позиции в заказе, а не цена за единицу.
- Один заказ = много позиций. Для получения состава заказа нужен JOIN с products.
- Связь через order_id - единственный способ добраться до категорий товаров в заказе, потому что у Purchase нет product_id.

### Определения метрик

| Метрика | Определение |
|---|---|
| Активный пользователь | Пользователь с хотя бы одним событием в customer_actions |
| Покупатель | Пользователь с хотя бы одним Purchase |
| Конверсия шага | Отношение числа пользователей на текущем шаге к числу на предыдущем шаге|
| Drop-off | Падение, считаем как "100% − конверсия шага" |
| Сквозная конверсия | Отношение пользователей на последнем шаге к первому |
